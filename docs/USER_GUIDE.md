# FlowLens 用户手册

FlowLens 是一款运行在本机的 HTTP/HTTPS 抓包与调试工具，用于捕获、检查、过滤、重放和导出本机网络流量。界面分为工具栏、过滤器栏、流量列表、详情面板和重放历史几个区域。

> 提示：本手册中的快捷键、按钮名称以当前版本界面为准。快捷键可在「设置 → 快捷键」中自定义。

---

## 1. 安装与启动

### 环境要求

- Windows 10/11（64 位）
- Microsoft Edge WebView2 运行时（多数 Windows 已内置，缺失时安装程序会提示）
- 抓包依赖 **Npcap**（如需捕获真实网卡流量，请先安装 Npcap 并在安装时勾选 WinPcap 兼容模式）
- 可选：**WinDivert**（无需代理即可解密 HTTPS，需以管理员身份运行）

### 启动

1. 双击 `FlowLens.exe`（或从开始菜单启动）。
2. 首次启动后，工具栏右侧会显示 CA 状态：`CA: 未安装` 或 `CA: 已安装`。
3. 若提示需要管理员权限（安装 CA 证书或捕获某些网卡时），请右键「以管理员身份运行」。

---

## 2. 安装根 CA 证书

要查看 HTTPS 请求/响应的明文内容，必须先把 FlowLens 生成的根 CA 安装到系统受信任的根证书存储区。

1. 打开 **设置 → 常规**（或工具栏的 CA 相关入口），点击 **生成 CA**（若尚未生成）。
2. 点击 **导出 CA（PEM）** 或 **导出二维码（QR）**，保存根证书文件。
3. 使用 **安装 CA** 功能（`install_ca`）将根证书写入 Windows 证书存储区；或在 Windows 中双击 PEM 文件 →「安装证书」→「本地计算机」→「受信任的根证书颁发机构」。
4. 安装完成后，工具栏 CA 状态应显示 `CA: 已安装`。
5. 完成后建议重启浏览器/目标应用，使其重新读取系统证书。

> 安全提醒：根 CA 赋予 FlowLens 为任意域名签发证书的能力。仅在需要诊断时安装，诊断完成后使用 **卸载 CA**（`uninstall_ca`）移除。

---

## 3. 开始 / 停止捕获

- **开始捕获**：在工具栏选择设备后点击「开始捕获」按钮（后端事件 `capture-started`）。状态栏「捕获」会变为 `进行中`。
- **停止捕获**：点击「停止捕获」按钮（后端事件 `capture-stopped`）。状态栏「捕获」变为 `已停止`。
- **暂停/恢复**：按 `Space`（默认快捷键）可暂停/恢复捕获；暂停期间已捕获但被挂起的会话可稍后释放。
- **清空事件**：点击工具栏「清空」或调用清空命令，流量列表与统计会被重置。

捕获过程中，底部状态栏实时显示「事件 N」与「捕获 进行中/已停止」。

---

## 4. 设备选择

1. 工具栏左侧有设备下拉框，列出可用网卡/接口（来自 `list_devices`，底层为 Npcap 设备列表）。
2. 默认选中第一个设备。
3. 选择要监听的网卡（例如「以太网」「Wi-Fi」「回环适配器 Npcap Loopback Adapter」）。
4. 若列表为空或报错「加载设备列表失败」，请确认已安装 Npcap，并以管理员身份重启 FlowLens。

---

## 5. 过滤器

过滤器栏位于流量列表上方，包含 5 个输入框与一个「清除」按钮。右侧实时显示「匹配数 / 总数」。

| 过滤器 | 含义 | 示例 |
|--------|------|------|
| **主机** | 按 URL / 主机片段匹配 | `example.com`、`api` |
| **进程** | 按进程名或 PID 匹配 | `chrome.exe` |
| **PID** | 仅按进程 ID 匹配 | `1234` |
| **方法** | HTTP 方法 | `GET`、`POST` |
| **状态** | HTTP 状态码 | `200`、`404` |

- 多个过滤器同时生效时取「与」关系（全部满足才显示）。
- 点击「清除」按钮重置所有过滤条件。
- 按 `Ctrl+F`（默认）可将焦点快速定位到过滤器输入框。

---

## 6. 详情面板

在流量列表中单击某条事件，右侧「详情面板」会展示该请求/响应的详细信息，包含以下标签页：

| 标签页 | 内容 |
|--------|------|
| **Headers** | 请求与响应头 |
| **Request Body** | 请求体（JSON 会自动格式化） |
| **Response Body** | 响应体（JSON 会自动格式化） |
| **Timing** | `timestamp_micros`、`time`、`size`、`session_id`、`paused`、`rewrite_applied` 等 |
| **TLS** | `tls_version`、`sni`、`cipher`、`src`/`dst`（非 TLS 事件显示「非 TLS 事件」） |
| **Process** | `process_name`、`pid`、`match_quality`、`protocol`、`kind` |

详情面板顶部还提供 **重放** 按钮和 **重放设置**（延迟毫秒数、自定义请求头），用于快速重放当前会话。

## 7. 导出 HAR

1. 打开 **设置 → 常规** 中的 HAR 导出区域（或工具栏导出入口）。
2. 点击 **导出 HAR**，在弹出的原生「保存」对话框中选择路径（默认文件名 `trace.har`）。
3. 勾选导出选项：
   - **包含请求/响应头**（`include_headers`）
   - **包含请求/响应体**（`include_bodies`）
   - **包含时序信息**（`include_timing`）
4. 确认后开始导出，成功后界面会短暂显示「已导出 HAR 到：…」。

导出的文件为 **HAR 1.2** 格式，可直接用浏览器开发者工具、Charles、Fiddler 等工具打开分析。

> 快捷键 `Ctrl+E`（默认）可快速触发 HAR 导出流程。

## 8. 会话重放

FlowLens 支持单个重放和批量重放。

### 单个重放

1. 在详情面板或流量列表中选中目标会话。
2. 在「重放设置」中设置：
   - **延迟（毫秒）**：重放前的等待时间，`0` 表示立即。
   - **自定义请求头**：每行一个 `Header: Value`，留空表示不改动。
3. 点击「重放」按钮。重放结果会写入右下角的「重放历史」，显示成功/失败、时间与会话 ID。

### 批量重放

1. 在流量列表中勾选多条会话（或全选）。
2. 点击「批量重放」，设置统一的延迟毫秒数。
3. 每条会话会按设定延迟依次重放，结果逐条写入重放历史。

重放历史面板支持「清空」。

## 9. 重写规则

「设置 → 重写」允许对匹配到的请求进行改写（URL、方法、请求头、请求体）。

### 添加规则

1. 填写 **匹配规则**（正则表达式，例如 `^https?://api\.example\.com/`）。
2. 填写 **替换值**（例如改写后的 URL）。
3. 设置 **优先级**（0–255 的整数，默认 100，数值越小优先级越高）。
4. 勾选 **启用** 后点击「添加」。校验失败时会在对应字段下方显示错误提示（如「匹配规则不是合法的正则表达式」）。

### 管理规则

- 规则列表显示：匹配值、替换值、优先级、启用开关、删除按钮。
- 切换 **启用** 开关即时生效；删除按钮移除规则。
- 规则由后端重写引擎（`flowlens_core::RewriteRule`）执行；详情面板 `Timing` 标签页的 `rewrite_applied` 会标记该请求是否被改写。

## 10. SNI 域名解密开关

通过 SNI 域名选择器控制哪些域名被解密（拦截）或直通（不拦截）。

1. 在域名输入框中输入域名，支持通配符 `*.example.com`（匹配单级子域名）。
2. 点击「添加域名」。新域名默认按当前策略加入列表。
3. 列表中每行域名带一个 **解密开关**：
   - 勾选「已解密」：该域名的 TLS 连接会被 FlowLens 终止并解密。
   - 取消勾选「已加密」：该域名的 TLS 连接直通，不修改。
4. 选中某行后可点击「删除」移除该域名。

> 建议：对使用证书固定（certificate pinning）的域名或敏感业务域名设置直通，避免连接失败。

---

## 11. 主题切换

- 点击工具栏「切换主题」按钮，或在「设置 → 常规」中切换 **深色 / 浅色**。
- 快捷键 `F2`（默认）可快速切换。
- 主题选择会被持久化（`read_theme` / `write_theme`），下次启动自动恢复；若未保存过则跟随系统偏好（浅色优先，否则深色）。

## 12. 快捷键

默认快捷键如下，全部可在 **「设置 → 快捷键」** 中修改：

| 动作 | 默认快捷键 |
|------|-----------|
| 聚焦过滤器 | `Ctrl+F` |
| 暂停/恢复捕获 | `Space` |
| 导出 HAR | `Ctrl+E` |
| 清除选择/过滤 | `Esc` |
| 切换主题 | `F2` |

### 自定义

1. 打开 **设置 → 快捷键**。
2. 点击对应动作的快捷键输入框，按下新的组合键（支持 `Ctrl`/`Alt`/`Shift` + 字母/功能键/方向键等）。
3. 若出现冲突，会提示「快捷键冲突：… 已被『…』占用」。
4. 可单条「重置」或全部「重置全部」恢复默认。
5. 自定义会持久化到 `shortcuts.json`（位于应用数据目录），下次启动自动加载。

## 13. 故障排查

| 现象 | 可能原因 | 解决办法 |
|------|---------|---------|
| 设备列表为空 / 「加载设备列表失败」 | 未安装 Npcap 或未授予权限 | 安装 Npcap（含 WinPcap 兼容模式），以管理员身份重启 FlowLens |
| 捕获不到任何流量 | 选错网卡 | 在设备下拉框选择正确的网卡（如以太网/Wi-Fi/回环适配器） |
| HTTPS 显示为乱码 / 无法解密 | 根 CA 未安装或不受信任 | 按「安装根 CA 证书」章节安装 CA，并重启目标应用 |
| 浏览器提示证书错误 | 目标域名被解密但应用使用证书固定 | 在「SNI 域名解密」中把该域名设为直通 |
| 高流量时界面卡顿 | 事件过多触发背压丢弃 | 调小事件上限（`设置 → 常规 → 事件上限`，范围 100–50000）或加大过滤条件 |
| 主题 / 快捷键设置丢失 | 临时目录被清理（主题、事件上限存于 temp） | 重新设置即可；快捷键存于应用数据目录，通常不会丢失 |
| HAR 导出失败 | 路径无写权限或被占用 | 选择有写权限的目录，或关闭正在占用该文件的程序后重试 |
| 重放失败 | 会话无 `session_id` 或目标不可达 | 确认会话包含有效 `session_id`，并检查网络连通性 |
| 快捷键不生效 | 焦点在输入框内，或与其他软件冲突 | 点击非输入区域后再试；或在设置中更换不冲突的快捷键 |

如仍无法解决，请收集「事件上限」「CA 状态」「设备列表」等信息后提交 Issue。
