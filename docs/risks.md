# FlowLens 风险与回退

## 主要风险

### 1. WFP 内核驱动风险
- **签名问题**: EV 证书需要 ~$300/年；测试阶段可能使用自签名证书
- **内核稳定性**: 驱动代码错误可能导致 BSOD
- **Windows 版本兼容**: 不同 Windows 版本 API 行为差异

### 2. 进程归属风险
- **快速进程退出**: PID 复用可能导致错误归属
- **ETW 事件丢失**: 高负载时可能丢失进程创建/退出事件
- **内核模式进程**: 系统进程永远不可归属具体 exe

### 3. TLS 解密风险
- **证书固定 (Pinning)**: 证书固定的应用将无法 MITM
- **TLS 1.3 Key Upgrade**: 需要正确处理 KeyLog API
- **私钥管理**: DPAPI 可能用户敏感；需要用户明确同意

### 4. 性能风险
- **环形缓冲区满**: 高并发时丢包
- **CPU 占用**: 解密和解析大量 CPU 密集操作
- **内存泄漏**: 长时间运行可能累积内存

### 5. 安全与合规
- **数据保护**: 明文 HTTPS 可被恶意利用
- **CA 信任**: 用户需要明确同意安装根证书
- **隐私**: MITM 所有流量可能泄露敏感信息

---

## 回退机制

| 场景 | 回退方案 |
|------|----------|
| WFP 驱动不可用 | 回退到 Npcap 用户态 |
| ETW 不可用 | IP Helper TCP/UDP 表 |
| IPv6 不支持 | IPv4-only 模式 |
| HTTP/2 解析失败 | 降级为字节流 |
| TLS 解密失败 | 记录损坏的 TLS ClientHello |
